# Mes Séances

App pour suivre la progression de mes films et séries (épisodes, saisons, minutes vues) et savoir quand une nouvelle saison sort.

En ligne : https://julienred.github.io/Mess-ance-/

Installation sur iPhone : ouvrir le lien dans Safari → Partager → « Sur l'écran d'accueil ».

Données gardées sur le téléphone. Infos séries : TVmaze. Infos films : iTunes.
